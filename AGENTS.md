# Инструкции для Агента

- **Генерация презентаций**: Все презентации создаются только в формате **PowerPoint (`.pptx`)**.
- **Удобство редактирования**: Все элементы слайдов (текст, списки, карточки, таблицы) должны быть нативными объектами PowerPoint, чтобы их можно было легко редактировать в MS PowerPoint.
- **Путь сохранения**: `03_Готовые_доклады/Презентация_<название>.pptx`.
