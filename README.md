# essay_generator: Генератор академических докладов по ГОСТу

Универсальный скрипт для автоматической генерации докладов, отчетов и научных работ в формате Microsoft Word (`.docx`) на **абсолютно любую тему**.

---

## Возможности

- **Генерация докладов на любую тему**: скрипт автоматически через LLM (нейросеть) составляет академический план доклада, пишет Введение, Главы, Параграфы, Заключение и Список литературы по ГОСТ Р 7.0.100-2018.
- **Оформление по ГОСТу**:
  - Шрифт Times New Roman, размер 14pt (заголовки 16pt/14pt bold).
  - Абзацный отступ 1.25 см, межстрочный интервал 1.5.
  - Поля страницы: Левое 3.0 см, Правое 1.5 см, Верхнее/Нижнее 2.0 см.
  - Нумерация страниц в правом нижнем колонтитуле со 2-й страницы.
  - Автоматическое динамическое оглавление MS Word.
  - Поддержка титульного листа МГТУ СТАНКИН с настройкой темы, дисциплины, ФИО студента и преподавателя.

---

## Как использовать

### 1. Интерактивный режим (через консоль)
Запустите главный скрипт без параметров, и он предложит ввести тему и параметры доклада прямо в консоли:

```bash
python 01_Скрипты_и_генераторы/main.py
```

### 2. Через аргументы командной строки
Вы можете сгенерировать доклад на любую тему в одну команду:

```bash
python 01_Скрипты_и_генераторы/main.py --topic "Применение искусственного интеллекта в медицине" --discipline "Информатика"
```

#### Доступные параметры:
- `-t`, `--topic` — Тема доклада *(любая произвольная тема)*
- `-d`, `--discipline` — Название дисциплины (по умолчанию: `Информационные технологии`)
- `-s`, `--student` — ФИО студента
- `-g`, `--group` — Группа студента
- `--teacher` — ФИО преподавателя
- `-o`, `--output` — Имя выходного `.docx` файла (по умолчанию генерируется автоматически)
- `-k`, `--api-key` — Ваш OpenRouter API Key (также поддерживается через переменную окружения `OPENROUTER_API_KEY`)

#### Примеры запуска на разные темы:

```bash
# Тема: Квантовые компьютеры
python 01_Скрипты_и_генераторы/main.py -t "Квантовые вычисления и их роль в современной криптографии" -d "Физика"

# Тема: Экономика
python 01_Скрипты_и_генераторы/main.py -t "Макроэкономический анализ финансовых рынков" -d "Экономика"
```

## Структура проекта

- `01_Скрипты_и_генераторы/`
  - `main.py` — **Главный универсальный CLI-генератор докладов на любую тему**.
  - `template_utils.py` — Единый модуль ГОСТ-верстки, стилей и формирования титульного листа.
  - `generate_plm_report.py`, `generate_car_classes_doc.py`, `generate_car_history_doc.py` — Примерные готовые доклады по конкретным темам.
- `02_Шаблоны_и_ресурсы/` — Файлы эталонных шаблонов и логотип.
- `03_Готовые_доклады/` — Директория, куда сохраняются сгенерированные `.docx` доклады.
